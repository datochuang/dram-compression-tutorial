## 冷讀者提出、這一版不改的地方

這些都不是重生條件。要不要做第二版，由負責人決定。

| 項目 | 冷讀者的意見 | 說明 |
|---|---|---|
| TLB miss 的觸發 | 左欄的 CPU MMU 到 kernel SW 之間沒有箭頭，這是第一段的核心卻最空 | 照 P1，TLB miss 一律進 kernel。第二版可以加一條「TLB miss」箭頭 |
| 多個 core | 寫了清每個 core 的 TLB，畫面只有一個 TLB | 這件事是第一段的難點之一 |
| 第二段的工作量 | 便條說「只換目的地」，checklist 卻有管理壓縮空間、選冷的 page | 框架不變，但這兩件是新的設計工作，不是沿用。第二版可以把便條改得不低估 |
| LZ4 HW 的位置 | 右欄上方的框沒有標籤，看不出 LZ4 HW 在 processor 裡或外 | 專案的架構圖把 LZ4 HW 放在 processor 外面 |
| 讀取來源 | 只畫了寫入的方向 | 刻意簡化 |
