## 冷讀者剩下的反駁，記錄不改

| 反駁 | 說明 |
|---|---|
| TLB clear 沒有路徑 | 介面列了清每個 core 的 TLB，圖上沒有箭頭回到各 core 的 TLB。用什麼機制清別的 core 的 TLB，平台資料目前不知道 |
| page fault 從哪裡發出 | 箭頭從 processor 框的邊出發，不是從 TLB miss handler。兩邊的邊界可能落在同一段 exception 程式裡 |
| 誰負責 WCET | 一次 fault 串起兩邊的時間，分開設計時由誰負責總時間，圖上沒有答案 |
| 右邊靠的是 proposal | ONE SHARED SET 的論點靠的是還不存在的 future HW assists |
| ONE PER CORE 的位置 | 貼在 page table 下面，第一眼可能讀成 page table 每個 core 一份 |
| 重複 | 便條與 Key point 幾乎一樣 |
